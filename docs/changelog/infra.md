# 인프라 변경 기록

## 2026-09-20

- AWS 환경변수 키가 없는 EKS에서 MinIO 자격 증명 체인이 예외로 멈춰 S3 문서 저장이 실패하던 문제를 수정했습니다. 환경변수 키가 없거나 비어 있으면 IAM/Web Identity provider로 넘어가며 기존 로컬·환경변수 자격 증명 동작은 유지합니다. STS 토큰 파일·갱신·S3 서명 회귀 테스트와 전체 test/bootJar를 통과했습니다. 실제 AWS 반영에는 새 이미지 게시 및 배포 검증이 필요합니다.

## 2026-09-17

- EKS 비관리자 Pod 설정에 맞춰 Document 실행 이미지를 UID/GID 10001로 변경했습니다. JAR·앱 경로는 root 소유로 유지하고 HOME·임시 경로만 쓰도록 합니다.
- 런타임 사용자·쓰기 권한 smoke를 통과했습니다. 전체 이미지 재빌드와 실제 API 기동 검증은 배포 전에 수행해야 합니다.
